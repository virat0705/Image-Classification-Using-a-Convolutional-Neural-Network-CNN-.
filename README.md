# Deep Learning Project: Image Classification with CNN

This beginner-friendly project trains a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset.

## Contents
- `main.py` — loads CIFAR-10, builds and trains a CNN, evaluates it, and saves the model.
- `requirements.txt` — Python dependencies.
- `report.md` — ready-to-edit project report.
- `run_instructions.txt` — how to install and run the project.

## Quick start
Use Python 3.10 or 3.11 in a virtual environment, then install the dependencies and run `python main.py`.
The first run downloads CIFAR-10 and may take a while. A GPU is optional; CPU training can be slow.
